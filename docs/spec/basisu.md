# basisu (Basis Universal transcoder)

Source: `external/basis_universal/transcoder/*`, `lib/src/basis_transcode.cpp`, `basis_sgd.h`.

- `basisu::bitreader`: `HuffmanDecodingTable`, `BitwiseDecoder` (zero bits past end,
  corrupt tree refs decode to 0), `ApproxMoveToFront`.
- `basisu::etc`: `Color32`, `Endpoint`, `Selector`, `DecoderEtcBlock`, inten tables.
- `basisu::etc1s::LowlevelEtc1sTranscoder`: `decode_palettes`, `decode_tables`,
  `transcode_slice` (block writes are bounds checked; out-of-range -> `Failed`),
  `transcode_image`. `TranscodeStatus { Ok, Failed, Unsupported }`.
- `basis_transcode`: `Texture2::transcode_basis(fmt, flags)` (ktxTexture2_TranscodeBasis),
  BasisLZ SGD parsing (`BasisLzGlobalHeader`, `BasisLzEtc1sImageDesc`).
- Verification: `tests/transcodetests.rs` compares SHA-256 of the output with the original
  C++ basisu transcode of the matching `.basis` (goldens from
  `scripts/golden/gen_transcode_golden.sh`, needs g++ + `./ref/ktx`).

Status (ETC1S targets): ETC1, ETC2 RGBA, EAC R11/RG11, BC1, BC3, BC4, BC5, BC7 (mode 5 +
chroma filter + mode 5 re-encoder), RGBA32, RGB565, BGR565, RGBA4444, ASTC LDR 4x4 done (byte exact).
`basisu::astc`: `convert_etc1s_to_astc_4x4` (HIGHER_OPAQUE_QUALITY=1 as native C++),
BISE trit encoding helpers reusable by UASTC; alpha indices come from a prior `Indices` pass.
`basisu::pvrtc`: PVRTC1 4bpp endpoint packing + `fixup_pvrtc1_4_modulation_rgb/rgba`
(pow2 only, Morton swizzled output; RGBA reads alpha indices from a temp `Indices` buffer).
`basisu::atc`: ATC/PVRTC2 shared match tables. `basisu::pvrtc2`: RGB (ATC-like) and RGBA
(constant-block mod 0/1/3 search, 4D PCA / 2D LA paths in f32, C evaluation order).
Tables: `src/basisu/tables.rs` generated by `scripts/gen_basisu_tables.py`; init-time tables built once via `OnceLock`.
UASTC LDR 4x4: `basisu::uastc` (uastc_init tables, unpack_uastc to ASTC desc / pixels,
pack_astc_block, transcode_uastc_to_astc), `basisu::uastc_ldr::LowlevelUastcLdr4x4Transcoder`
(transcode_slice/image), `Texture2::transcode_uastc_ldr_4x4` (transcodeUastcLDR4x4).
Tables: `src/basisu/uastc_tables.rs` from `scripts/gen_uastc_tables.py`.
Verification: `tests/transcode_uastc.rs` vs `golden/transcode_uastc.txt` (every level of 4 UASTC
files, flags 0 and HIGH_QUALITY). Done: ASTC, BC7 (`basisu::uastc_bc7`, encode_bc7_block
for all BC7 modes), RGBA32, RGB565, BGR565, RGBA4444; PVRTC2 rejected like C. ETC1/ETC2 RGBA in `basisu::uastc_etc`
(goldens also cover TRANSCODE_ALPHA_DATA_TO_OPAQUE_FORMATS). BC1/3/4/5 in `basisu::uastc_bc1`
(encode_bc1 PCA+LS, encode_bc4, hint0/hint1; encode_bc1_alt unused by the transcoder, not ported).
EAC R11/RG11 (pack_eac, pack_eac_high_quality)
in `basisu::uastc_etc`. PVRTC1 RGB/RGBA in `basisu::uastc_pvrtc` (reuses the ETC1S
fix-up pass; C ignores its result, so does the port). Goldens size PVRTC1 images like libktx
(2x2 block minimum).

UASTC HDR 4x4: `basisu::astc_helpers` (astc_helpers: unpack_block, decode_block for
SRGB8/LDR8/HDR16/RGB9E5, half/9E5 packing, ISE dequant tables; `m_weights`/`m_solid_color`
union emulated by `LogAstcBlock::solid_color`), `basisu::bc6h` (pack_bc6h_block, the
1/2-subset BC6H encoders, decode_mode7/11_to_qlog12, astc_hdr_transcode_to_bc6h),
`basisu::uastc_hdr::LowlevelUastcHdr4x4Transcoder` (ASTC HDR copy, BC6H, RGB/RGBA half,
RGB9E5), `Texture2::transcode_uastc_hdr_4x4` (transcodeUastcHDR4x4, shares the level loop
with the LDR path). Tables: `src/basisu/hdr_tables.rs` from `scripts/gen_hdr_tables.py`.
Verification: `tests/transcode_uastc_hdr.rs` vs `golden/transcode_uastc_hdr.txt`.
`astc_helpers::pack_astc_block` (encode_bise, config bits, void extents) and the full
`dequant_table` (val_to_ise, ISE_to_rank, rank_to_ISE) back the 6x6 path.

UASTC HDR 6x6 intermediate: `basisu::astc_6x6_hdr` (decode_6x6_hdr: run/solid/reuse/block
codes, 5-row reuse ring buffer, endpoint deltas via rank tables, requantize_ise_endpoints with
the preserve2/3 tables, copy_weight_grid incl. the SIG0 `orig_behavior` 2x2 upsample quirk;
fast_encode_bc6h: simple/complex 1-subset LS + 2-subset patterns, f32 in C order, C int wrap
emulated), `basisu::uastc_hdr_6x6i::LowlevelUastcHdr6x6IntermediateTranscoder` (ASTC HDR 6x6
copy, BC6H via 12x12 texel tiles, RGB/RGBA half, RGB9E5),
`Texture2::transcode_uastc_hdr_6x6_intermediate` (SGD `ktxUASTCHDR6x6IntermediateImageDesc`
seek table, exact-size check). Tables (block mode descs, reuse deltas, partition seeds, trit/quint
encode) generated into `hdr_tables.rs`. Goldens cover flags 0 and HIGH_QUALITY (2-subset BC6H).
Todo: ATC, FXT1 (not reachable from libktx); video P-frames untested.

Test guard: `texture_combinations_test_basic` asserts the number of golden comparisons,
and `bc7_chroma_filter_is_exercised` proves the BC7 filter path is covered.

## miniz deflate (`basisu::miniz`)

Port of the `tdefl` half of `encoder/basisu_miniz.h` (miniz 1.x) plus `mz_compress2`,
`mz_compressBound`, `mz_adler32`, `tdefl_create_comp_flags_from_zip_params`. libktx's ZLIB
supercompression (`miniz_wrapper.cpp` -> `zlib.rs`) deflates through it. The x86-64 configuration
is ported: 16-bit word compares in `tdefl_find_match` (probes counted in groups of 3, `u16`
distance wrap), `tdefl_compress_fast` for level 1 (4 KiB lookahead, 12-bit trigram hash), zlib
header always `78 01`. The 64-bit `tdefl_compress_lz_codes` is replaced by the portable variant
(same bit stream). Output goes to a growing buffer instead of the caller's/internal 85 KiB
buffer (same bytes); a too small destination still yields `MZ_BUF_ERROR` -> `OutOfMemory`.
Dictionary/chains are zero-initialised (miniz mallocs them; unwritten bytes never reach output).
Inflate stays on `miniz_oxide` (inflate output is unique).
Tests: `tests/miniz.rs` vs `scripts/golden/gen_miniz_golden.sh` (768 cases: tdefl levels 0..10 x
5 strategies, raw/zlib, mz_compress2 1..9; synthetic inputs up to 1 MB and test files).
