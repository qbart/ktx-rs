# ktx CLI (tools/ktx)

Source: `tools/ktx/*` (command.h/.cpp, ktx_main.cpp, validate.*, validation_messages.h,
formats.h, utility.h) and the used parts of `external/cxxopts` 3.1.1.

Layout: library module `ktx::cli` + thin binary `src/bin/ktx.rs` (args via `args_os`, lossy).

- `options.rs`: cxxopts port. Long/short/grouped flags, `--x=v`, positional list, `unmatched()`,
  `--` handling, `value<uint32_t>` (`.u32()`: `integer_parser`, decimal/0x hex, C overflow
  check, negatives rejected), bool parsing (`t|T|true|True|1`, `f|F|false|False|0`), error texts with ASCII
  quotes, help layout (`format_option`, `format_description` wrap at width 100, groups sorted).
- `command.rs`: `ReturnCode`, `FatalError(rc)` returned as `Err` (exceptions -> `Result`),
  `Reporter` (`warning/error/fatal/fatal_usage` print to stderr), `OptionGroup` trait for
  `OptionsGeneric/Format/SingleIn` (`Combine`: init left->right, process right->left),
  `InputStream` (file or all of stdin in memory), `OptionsSingleInSingleOut<OPTIONAL>`,
  `OutputStream` (truncating create or stdout; `writeKTX2` removes the file on failure),
  `validate_tool_input` (issues to stderr), `runtime_error` (`std::exception` -> exit 4).
- `fmt.rs`: `{fmt}` subset (`{}`, `{:d}`, `{:08b}`, `{:08X}`, `{{`); `try_format` fails with
  "argument not found" like `fmt::format` when a placeholder lacks an argument.
- `validate.rs`: `ValidationContext` over in-memory data (C++ IOStream/Memory variants give the
  same output). Fatal issues unwind as `Stop::Fatal` (exit 3); an escaping `format_error`
  becomes `Err(what)` -> `ktx validate fatal: <what>`, exit 4. Bitfield structs decoded from
  LE words; C u32/size_t wraps kept (`calcImageSize` in u32, KVD/DFD offset sums, shifts mask
  like x86). `lcm(0,4)` = 0 alignment guarded (C divides by zero).
- `validation_messages.rs`, `formats_gen.rs`: generated by `scripts/gen_cli_tables.py`.
- Commands: `validate` (text / json / mini-json); `info` (`command_info.rs`: validator messages +
  `info.rs` writers over a `MemStream`, KTX1 text only, JSON trailing-comma workaround kept;
  info errors are ignored when validation failed, like C++); `transcode` (`transcode_utils.rs`:
  target table, `determineTranscodeSwizzle`, RGBA8 -> R/RG/RGB conversion into a fresh texture
  (drops source KV data like C++), in-place swizzle; `deflate_utils.rs`: `OptionsDeflate`;
  rewrites `KTXwriter` / `KTXwriterScParams`); `help` (runs `man`, page next to the
  executable first; Windows opens the html page); `deflate` (`command_deflate.rs`: warning for
  ZLIB/ZSTD input, fatal for BasisLZ; `--warnings-as-errors` parsed but unused like C++; the
  `std::regex_search` patterns for old deflate options are hand-written byte matchers with
  ECMAScript greedy semantics); `extract` (`command_extract.rs`, `fragment_uri.rs`:
  `SelectorRange` with u32 wraps, `parseFragmentURI`, `std::stoi` emulation with libstdc++
  `what()` = "stoi"; selection checks incl. the C++ off-by-one depth check; whole-3D raw path;
  `saveImageFile` format switch ported; `savePNG` via `lodepng` (sBIT / sRGB / gAMA / cHRM, 16-bit
  big endian input); `format_descriptor.rs`: `createFormatDescriptor`, `find`, `removeLastChannel`,
  `extract_bits`, `convertUNORM` and the float conversions (`convertSNORMToFloat` keeps the C++
  non sign-extended raw bits, `convertSIntToFloat` sign-magnitude, glm `packed1xbitToFloat` gives
  -1 for NaN/Inf codes); `saveEXR` via `tinyexr` (ABGR channel order, ktxMapRange forces FLOAT,
  chromaticities attribute); `decodeAndSaveASTC` via `astcenc` (U8 / F16 / F32 with ktxMapRange);
  `unpackAndSave422` (V, Y, U order, linear chroma interpolation, `remap`, `convertFloatToUNORM`);
  filesystem errors mimic libstdc++ `filesystem_error::what()`). Others: todo.

Tests: `tests/cts.rs` ports `clitest.py` (incl. its `expected[start:-1]` quirk after the last
backtick regex) and runs every validate, info, help, transcode, deflate and extract case of KTX-Software-CTS 59f0a653 against the binary
(data in `tests/resources/cts`; `ktx2_sample` inputs > 128 KiB are listed in `NOT_VENDORED.txt`
and their subcases skipped; they pass with the upstream runner). `outputs` files must match
exactly. `scripts/vendor_cts.py <command>` copies a command's cases and every file its runnable subcases
reference. `tests/validate.rs`: corrupted files never panic.
