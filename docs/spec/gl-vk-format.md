# gl_format / vk_format

Source: `lib/src/gl_format.h`, `lib/src/vk_format.h`. Generated by
`scripts/gen_gl_format.py` (C subset translator: switch/case groups, return,
ternary, `pFormatSize->field =`, ASTC `SELECTED` macros; debug `assert`s dropped).

- `gl_format.rs`: all `GL_*` constants (u32), `gl_get_format_from_internal_format`,
  `gl_get_type_from_internal_format`, `gl_get_type_size_from_type`, `gl_get_format_size`.
- `vk_format.rs`: `RgbaAstcMapping {ToHdr, ToLdr}`, `vk_get_format_from_opengl_format`,
  `vk_get_format_from_opengl_type`, `vk_get_format_from_opengl_internal_format`,
  `vk_get_format_size`. Vulkan `_EXT/_KHR/_IMG` aliases map to core names.

Status: complete.

## vk2gl.h (`src/vk2gl.rs`)
`vk_format2gl_internal_format` / `vk_format2gl_format` / `vk_format2gl_type`: generated by
`scripts/gen_vk2gl.py` from the `vkFormat2gl*.inl` switch bodies (GL names resolved through
`vk2gl.h`, `glcorearb.h`, `glext.h`, `gl2ext.h`); unknown formats give `GL_INVALID_VALUE`. Used by
the GL loader. Test: `tests/vk2gl.rs` vs the compiled C header for all 296 VkFormat values
(`scripts/golden/gen_vk2gl_golden.sh`).
