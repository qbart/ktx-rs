# Basis Universal encoders (`ktxTexture2_CompressBasisEx`)

Goal: pure Rust port of the basisu encoder paths reachable from libktx `basis_encode.cpp`:
BasisLZ/ETC1S, UASTC LDR 4x4 (+RDO), UASTC HDR 4x4 and UASTC HDR 6x6 intermediate, driven by
`basis_compressor` (`basisu_comp.cpp`). Reference build: libktx on x86_64 compiles basisu with
`-msse4.1 -DBASISU_SUPPORT_SSE=1` (CMake `BASISU_SSE` defaults ON), no OpenCL, so the goldens
link `scripts/golden/build_basisu_encoder.sh` (`$WORK/libbasisu_enc.a`) with that config.

Port order (each stage bit exact vs. the C++ build before the next one starts):
1. [x] `basisu_etc.cpp` ETC1 block encoder (`src/basisu/etc_enc.rs`)
2. [x] UASTC LDR 4x4: `basisu_bc7enc.cpp` (`src/basisu/bc7enc.rs`), block encoder
   (`basisu_uastc_enc.cpp` `encode_uastc`, `src/basisu/uastc_enc.rs`), RDO (`uastc_rdo`)
3. [~] ETC1S: [x] vector quantizer (`basisu_enc.h` `tree_vector_quant`, `src/basisu/vq.rs`),
   [ ] frontend (`basisu_frontend.cpp`: VQ, clusterization) + backend (`basisu_backend.cpp`:
   endpoint/selector palettes, Huffman) + KTX2 BasisLZ global data
4. [ ] `basis_compressor` pipeline (`basisu_comp.cpp`) and libktx `basis_encode.cpp`
5. [ ] UASTC HDR 4x4 (`basisu_uastc_hdr_4x4_enc.cpp`, `basisu_astc_hdr_common.cpp`)
6. [ ] UASTC HDR 6x6 intermediate (`basisu_astc_hdr_6x6_enc.cpp`)

## Shared helpers (`basisu::enc`)

`color_rgba` as `[u8; 4]` with clamping / no-clamp constructors, `color_distance` (perceptual
14/45/5 luma, 26/3 chroma weights, u32 wrap as in C; linear squared distance), `hash_hsieh`,
`indirect_sort` (C++ uses unstable `std::sort`; current callers only depend on key order).

## ETC1 encoder (`basisu::etc_enc`)

`etc_block` (`EtcBlock`, big endian bit layout, all pack/unpack/selector helpers),
`unpack_etc1`, `etc1_optimizer` (cluster fit with `g_cluster_fit_order_tab`, neighborhood scan +
refinement, Bloom filter of tried colors via `hash_hsieh`, slow/fast evaluators incl. the
`g_eval_dist_tables` skip for medium quality and the luma sorted fast classifier),
`pack_etc1_block_solid_color` (`g_etc1_inverse_lookup` built once via `OnceLock`),
`pack_eac_a8`. Tables generated by `scripts/gen_basisu_etc_tables.py` into `etc_enc_tables.rs`.
- The SSE 4.1 kernels (`find_selectors_*`, `*_distance_rgb_4_N`) compute the same int32
  distances and only differ in early-out granularity, which never changes accepted solutions;
  the scalar path is ported.
- C++ quirk kept: `etc1_optimizer::params::m_use_color4` shadows the base
  `basis_etc1_pack_params::m_use_color4` (`Etc1OptimizerParams::use_color4` vs `pack.use_color4`).
- `init`/`compute` take the params explicitly (no stored `m_pParams`/`m_pResult` pointers);
  `results::m_pSelectors` becomes an owned `Vec<u8>` (resized to `n` when shorter).
Tests: `tests/basisu_etc.rs` vs `scripts/golden/gen_basisu_etc_golden.sh` (3000 blocks x 64
optimizer configs: quality, perceptual, cluster fit, color4, 8/16 pixels, scan deltas, base
color constraint, forced selectors, refinement; block helpers on results and random blocks;
solid color; EAC A8).

## bc7enc (`basisu::bc7enc`)

`color_cell_compression` (PCA endpoints, least squares refinement, uber levels 1..4, single
color fallbacks for BC7 mode 1 and ASTC 4-bit 3-bit, 4-bit 2-bit RGBA, range 7/13 2-bit, range
11 5-bit), `color_cell_compression_est_astc`, the `g_*_weights*x` least squares tables and
`bc7enc_compress_block_init` tables (`bc7enc_tables()`, built once via `OnceLock`).
- `color_cell_compressor_results::m_pSelectors/_temp` become owned `[u8; 16]` arrays; the
  single color packers return their selector index and the caller fills the arrays.
- Float semantics follow the SSE build (no FMA contraction): f32 math, f64 normal equations
  with f32 products accumulated, `(int)` truncation; u32 wrapping in weighted distances.
- `check_best_overall_error` is `_DEBUG` only in C++ and not ported.
Tests: `tests/basisu_bc7enc.rs` vs `scripts/golden/gen_basisu_bc7enc_golden.sh` (1400 blocks x
16 range/mode configs x 12 variants: perceptual, uber level, least squares passes, pixel count,
forced selectors; `est_astc` over 6 weight tables, 3/4 comps, weights, early out).

## UASTC LDR 4x4 encoder (`basisu::uastc_enc`)

`encode_uastc` (levels fastest..very slow, favor UASTC/BC7 error, ETC1 hint flags, favor simpler
modes), all 19 mode encoders, `pack_uastc` (Huffman mode, hints, BISE endpoints, anchor weight
inversion), BC1 hint selection (`encode_bc1` + `transcode_uastc_to_bc1_hint0/1`), ETC1 hint
search (flip estimate, sorted bias table, YCbCr error) and `uastc_pack_eac_a8`.
Decoders needed for the error checks: `unpack_bc1` and `bc7u::unpack_bc7` (`basisu::gpu_texture`).
- The repeated C++ mode functions are folded: one subset modes (0, 1, 5, 10, 12, 14, 18), 2
  subset RGB (2, 4), dual plane (6, 11, 13, 17); per mode tables keep the C++ constants.
- `results[MAX_ENCODE_RESULTS]` becomes a capped `Vec`; `BASISU_VALIDATE_UASTC_ENC` (debug only)
  checks are not ported.
Tests: `tests/basisu_uastc_enc.rs` vs `scripts/golden/gen_basisu_uastc_enc_golden.sh` (3000
blocks incl. LA and near opaque kinds x levels 0..4 + 6 flag variants; random BC1 / BC7 decode).

## UASTC RDO (`basisu::uastc_enc::uastc_rdo`)

`uastc_rdo` / `uastc_rdo_blocks` (selector bit pattern copying from the previous
`lz_dict_size / 16` blocks, smooth block error scale, skip threshold, literal / tdefl match cost
estimate, mode 0 endpoint refinement with forced selectors), `uastc_recompute_hints`.
- `selector_history` (`std::unordered_map`, never iterated) becomes a `HashMap<(ofs, sel), u32>`.
- The job pool split (`num_blocks / total_jobs` independent ranges, each with its own history)
  runs on `std::thread::scope`; output depends only on `total_jobs`. Returns `(ok, stats)`; the
  stats are the C++ `debug_printf` counters.
- `tdefl` distance extra bit tables are computed in `const` instead of listed.
Tests: `tests/basisu_uastc_rdo.rs` vs `scripts/golden/gen_basisu_uastc_rdo_golden.sh` (11
generated 96x64 images incl. alpha, high noise and tiled ones x 16 configs: lambda, dict size,
literal cost, RMS ratio / skip threshold, smooth block params, refinement, levels and hint flags
for the recompute, 1 / 4 / 7 jobs).

## Vector quantizer (`basisu::vq`)

`priority_queue`, `tree_vector_quant<vec<N, float>>` (`generate`, the three `retrieve`
overloads as `retrieve` / `retrieve_origins` / `retrieve_max`, PCA split axis, k-means refine,
unsplittable node fallbacks), `compute_pca_from_covar`, `generate_hierarchical_codebook_threaded`
(+ `_internal`).
- `std::map<vec, weighted_block_group>` becomes a `BTreeMap` keyed by `vec::operator<`
  (lexicographic, `-0.0 == 0.0`), so unique vector order matches.
- The SSE 4.1 `update_covar_matrix_16x16` kernel evaluates the same per element products as the
  scalar loop; only the scalar loop is ported. The job pool clusterizers (>= 262144 unique
  vectors) run on `std::thread::scope`.
- C++ quirk kept: the `prep_split` fallback sorts along the largest axis but splits in unsorted
  order (sorted indices unused).
Tests: `tests/basisu_vq.rs` vs `scripts/golden/gen_basisu_vq_golden.sh` (6 vector kinds incl.
duplicates, signed zeros and 1e-7 perturbations x 7 sizes x 5 codebook sizes, weights, parent
codebooks, even/odd pairs, N = 6 and 16; threaded path on 270000 unique vectors).
