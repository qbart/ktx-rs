# astcenc decompressor (external/astc-encoder)

Source: `astcenc_entry.cpp` (`astcenc_config_init`, `astcenc_context_alloc`,
`astcenc_decompress_image`, `astcenc_get_error_string`), `astcenc_block_sizes.cpp`,
`astcenc_partition_tables.cpp`, `astcenc_integer_sequence.cpp`, `astcenc_symbolic_physical.cpp`,
`astcenc_color_unquantize.cpp`, `astcenc_decompress_symbolic.cpp`, `astcenc_image.cpp`,
`astcenc_vecmathlib*.h` (scalar equivalents). Tables (`src/astcenc/tables.rs`) are generated by
`scripts/gen_astcenc_tables.py` from `astcenc_integer_sequence.cpp`,
`astcenc_weight_quant_xfer_tables.cpp`, `astcenc_quantization.cpp`.

- Target build: KTX-Software x86-64 (AVX2, F16C, POPCNT, `-ffp-contract=off`). Emulated details:
  `_mm_min_ps` / `_mm_max_ps` NaN rules (second operand wins), `float_to_int_rtn` = truncate(x+0.5),
  F16C round-to-nearest-even float->half with quietened NaNs, and the signed saturation of
  `_mm_packs_epi32` in vector `float16_to_float` (constant F16 void-extent colors >= 0x8000 decode
  to NaN, i.e. magenta in U8 output).
- Block size descriptor without mode / partitioning omission (non SELF_DECOMPRESS_ONLY): all
  legal block modes (astcenc's 109 / 111 weight bit limits), decimation tables per weight grid,
  all 1024 partitionings per count; 2D and 3D block sizes.
- `astcenc_config_init` keeps only profile, flags and block size (validated like C: block size,
  quality range, flags, UNORM8 + HDR decode mode); compressor tuning presets are not ported.
- Image API: `AstcencImage` with `AstcencImageData::{U8, F16, F32}` planes (one per z slice).
- Not ported yet: the compression kernels (in progress, see below), threads (single threaded).

## Compressor (in progress)

Target: KTX's AVX2 build with invariance on (`vfloat` = 8 lanes, `vfloatacc` = 4 lanes).
- `vecmath.rs`: lane-exact `vfloat4/vint4/vmask4` (SSE 4.1) and `vfloat8/vint8/vmask8` (AVX2):
  `minps/maxps` NaN order, ordered compares, cvtt overflow, `abs(-0) == -0` for 4-wide,
  `hmin/hmax/hadd_s/haccumulate` reduction orders, `exp2/log2/pow/atan2/float_to_lns` approximations.
- `config_init`: all presets (high / mid / low bandwidth), LERP interpolation, profile and flag
  tuning; `validate_config` clamping and the dB limit to MSE conversion in `context_alloc`.
- `internal.rs`, `block_sizes.rs`, `partition_tables.rs`, `percentile_tables.rs` (generated by
  `scripts/gen_astcenc_percentile.py`): the compressor `block_size_descriptor` with percentile
  based block mode selection, decimation tables incl. SIMD tail padding, partitionings with
  duplicate removal, k-means texel selection (xoroshiro128+) and coverage bitmaps.

- `image.rs`: `load_image_block` (U8 / F16 / F32, swizzle, UNORM16 / LNS encoding, edge
  clamping; F16 texels go through `_mm_packs_epi32`, so negative halves load as NaN) and
  `load_image_block_fast_ldr`. `compute_variance` (alpha scale radius) is not needed by KTX.
- `averages_and_directions.rs`: partition averages, `compute_avgs_and_dirs_{2,3,3_rgb,4}_comp`,
  `compute_error_squared_{rgb,rgba}` with 8-lane loops / 4-lane accumulators.

- `ideal_endpoints_and_weights.rs`: ideal endpoints / weights for 1-4 components, 1 and 2
  planes; decimated ideal weights with one refinement step; weight quantization through
  `quant_and_xfer_tables` (generated); weight set errors; least squares endpoint, RGBS and
  RGBO recomputation. C++ quirks kept: the 4 component path leaves `ep.partition_count`
  untouched, omitting component 0 weights components 0..2.

Tests: `tests/astcenc_weights.rs` (432 block cases vs `scripts/golden/gen_astcenc_weights_golden.sh`),
`tests/astcenc_kernels.rs` (4608 cases vs `scripts/golden/gen_astcenc_kernels_golden.sh`,
calling the C++ internals directly; NaN payloads canonicalized), `tests/astcenc_bsd.rs` (5280 cases vs `scripts/golden/gen_astcenc_bsd_golden.sh`: 24 block
sizes × 11 qualities × 10 flag sets × 2 profiles; config hashes and full descriptor hashes).

Tests: `tests/astcenc.rs`, 576 cases vs `scripts/golden/gen_astcenc_golden.sh` (pseudo random
blocks incl. void-extent, every 2D/3D block size, 4 profiles, 3 output types, 2 swizzles).
